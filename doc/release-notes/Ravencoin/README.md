# Historical Upstream Ravencoin Release Notes

The files in this directory are preserved upstream Ravencoin release notes.
They are retained for historical attribution and reference only.

These documents reflect the Ravencoin project's development history and contain
Ravencoin-specific branding, version numbers, and feature descriptions that do
not apply to Hemp0x Core Next.

Current Hemp0x release notes are maintained separately in `doc/release-notes.md`
and the project's GitHub releases page.

Do not treat the content of these files as authoritative for Hemp0x behavior,
features, or configuration.
