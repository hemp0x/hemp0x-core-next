How to Upgrade
==============

If you are running an older version, shut it down. Wait until it has completely
shut down (which might take a few minutes for older versions), then run the
new hemp0xd binary.

Compatibility
==============

Hemp0x Core is extensively tested on multiple operating systems using
the Linux kernel, macOS 10.15+, and Windows 10 and later.

Hemp0x Core should also work on most other Unix-like systems but is not
frequently tested on them.
