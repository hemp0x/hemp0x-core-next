macOS release notes
===================

The old deterministic DMG process is no longer used for Hemp0x Core Next
release builds. Core Next does not ship the old bundled Qt wallet GUI or macOS
DMG installers.

For native macOS source builds, use [build-osx.md](build-osx.md). If
deterministic macOS command-line release archives are reintroduced later, this
document should be replaced with the current builder requirements and artifact
verification process.
