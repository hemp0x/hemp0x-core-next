Hemp0x Core Release Notes
=========================

The current Core Next release notes are maintained in
[release-notes-core-next.md](release-notes-core-next.md).

Core Next is the modernization branch for Hemp0x Core. The first release keeps
live Hemp0x consensus behavior unchanged while updating build, dependency,
wallet, RPC, P2P, messaging, and release infrastructure around the existing
network.

Before publishing a release, verify the final tagged source tree and release
artifacts against [release-process.md](release-process.md).
